LIVE OpenTimestamps LIVE — Real OTS calendar submission via proxy
What's real: SHA-256 hashing in your browser. Server-side proxy submits hashes to real OTS calendar servers. Verification against real Bitcoin blockchain data via mempool.space API.
What's simulated: Nothing — OpenTimestamps is fully operational via server-side proxy.

HOW IT WORKS

  1. Browser computes SHA-256 hash of your document
  2. Hash is sent to server-side proxy which submits to OTS calendar servers
  3. Calendar servers aggregate hashes into a merkle tree anchored to Bitcoin
  4. Verification checks against real Bitcoin blockchain data via mempool.space API
