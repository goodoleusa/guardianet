ABOUT IPFS PINNING
What is pinning? IPFS nodes automatically discard files that aren't "pinned" — pinning tells your node (or a service) to keep a file indefinitely. Each additional pinner is an independent mirror in a different jurisdiction.

What is a CID? A Content Identifier is a cryptographic fingerprint of a file. The same file always produces the same CID. If anyone changes even one byte, the CID changes — making tampering detectable and impossible to hide.

Why not just save a URL? URLs can return 404. Domain names can be seized. Hosting providers can delete content under legal pressure. A CID addresses content by what it is, not where it lives. 200 mirrors across 40 countries with the same CID = effectively uncensorable.

Privacy note: Running your own IPFS node makes your IP address visible to others fetching the same content. If this is a concern for your threat model, use a pinning service (Pinata, web3.storage) rather than a local node.
